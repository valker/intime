# InTime

Приложение для повторяющихся задач: сделать перерыв каждый час, полить цветы раз
в три дня, передать показания счётчиков раз в месяц. Работает локально, без аккаунта,
сервера и рекламы.

Список показывает задачи по сроку. Короткое нажатие открывает детали, где можно
подтвердить, отредактировать или удалить задачу. После подтверждения следующий
срок рассчитывается от фактического времени ACK с учётом интервала и делителя.
Уведомления зависят от разрешений Android и состояния канала; без разрешения
точных будильников используется неточное планирование.

## Данные и резервные копии

Текущая реализация — Java/XML, ViewModel/LiveData и Room, схема базы **6**.
Миграции поддерживают исторические схемы 4 → 5 → 6 и 5 → 6.
Даты задач хранятся в Unix-миллисекундах. Помимо полей резервной копии база
содержит `wasNotified`, который не переносится при импорте.

В настройках доступны импорт и экспорт JSON через системный выбор файлов.
Экспорт содержит `meta.version = 1`, `meta.exportedAt` и `tables.tasks`:
`columns` задаёт порядок восьми полей, `rows` содержит массивы значений.

```json
{
  "meta": { "version": 1, "exportedAt": 1736345234000 },
  "tables": {
    "tasks": {
      "columns": ["id", "description", "interval", "amount", "next_alarm", "next_caution", "last_ack", "quant"],
      "rows": [[1, "Полить цветы", 2, 3, 1736604434000, 1736591474000, 1736345234000, 1]]
    }
  }
}
```

Файл записывается в UTF-8. Импорт полностью заменяет список после проверки всех
строк; при ошибке валидации или вставки прежние задачи сохраняются. Контракт,
ограничения чисел и совместимость старых файлов — [BACKUP_FORMAT.md](BACKUP_FORMAT.md).
Формат старого SQLite-экспорта из v1 не является форматом текущего экспортера.

## Разработка и проверки

Проверенное окружение: JDK 17, Gradle Wrapper 8.11.1, AGP 8.9.1, SDK 36,
minSdk 24. По умолчанию сборки используют пакет `.dev`; production включается
явно с проверкой версии и подписи, см. [RELEASE.md](RELEASE.md).

Команды юнит-, интеграционных и release smoke-тестов, требования эмулятора —
[TESTING.md](TESTING.md). GitLab CI и GitHub Actions запускают lint, debug-сборку
и локальные тесты. Тесты GitLab на устройстве требуют отдельного runner с KVM.
Добавление CI-конфигурации не подтверждает успешность удалённого прогона.

Текущее состояние и следующие шаги — [ROADMAP.md](ROADMAP.md), выполненные
проверки и границы покрытия — [DEVICE_TEST_RESULTS.md](DEVICE_TEST_RESULTS.md).
Обновление приложения из Google Play с отдельной копией реальных данных пока
не подтверждено; маршрут и требования подписи — [UPGRADE.md](UPGRADE.md).
