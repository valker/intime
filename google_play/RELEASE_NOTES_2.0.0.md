# Release notes 2.0.0 — черновик

Параметры: package `com.vpe_soft.intime.intime`, versionCode 28, versionName 2.0.0.
Название выбрано пользователем; код 28 отсутствовал в снимке Play от 11 октября.
Повторить сверку перед загрузкой. Артефакты 28 собраны 11 октября, проверки подписи,
манифестов и AAB прошли. CRUD/JSON/reboot финального APK проверены на API 31/33/35/36;
доставка/ACK и запрет/восстановление уведомлений/канала также проверены на этих API.
Повторные fallback/idle/worker и Play upgrade тесты этой версии отменены
пользователем 11 октября с принятием соответствующих результатов 27;
свежий PASS этих сценариев для 28 не заявляется. Далее подготовка выпуска R5.5.
Текст не отправлялся в Console. Нет утверждения о покрытии всех устройств или гарантированном сроке
фоновых повторов.
